# Toolchain

Working notes, ledgers and SQL for the daily puzzle site.

Until 22 Nov 2026 this folder also held the Noodle News build toolchain (house template,
`dn-build.py`, `dn-briefing.js`, the gates, rubric, style guide and desk notes) and some game
notes. They moved with News and Games when dailynoodle.co.uk became puzzles only:

- News toolchain: `alecldarlow-cell/dailynoodle-news`, `toolchain/`
- Game notes (Echo Cave, Inkline, Paper Planes): `alecldarlow-cell/dailynoodle-games`, `toolchain/`

What is here: puzzle editing guides and ledgers (Link, Mini, Reckon), cryptic and Link batches,
testing (`testing.md`), site sections and tracking (`site-sections-and-tracking.md`), the admin
and database SQL (`sql/`), the push edge function (`edge/`).
